# Leertasten-Klicker – statische Website

Reines HTML, CSS und JavaScript, flache Struktur für GitHub Pages (`/seite` lädt `seite.html`).

| URL | Haupt-Keyword |
|---|---|
| `/` | Leertasten Klicker (Leertaste Test, Speed Test, CPS Test) |
| `/leertaste-zaehler` | Leertaste Zähler |
| `/1-sekunde` … `/100-sekunden` | Leertaste Test X Sekunden (Spacebar Clicker X Seconds) |
| `/reaktionstest-leertaste` | Reaktionszeit Test Leertaste |
| `/wie-schnell-leertaste-druecken` | Wie schnell kann ich die Leertaste drücken |
| `/leertaste-schneller-druecken` | Leertaste schnell drücken |
| `/ratgeber`, `/ueber-uns`, `/kontakt`, `/datenschutz`, `/nutzungsbedingungen`, `/haftungsausschluss` | Hub- und Rechtsseiten |

Deploy: Organisation `leertasten-klicker`, Repository `leertasten-klicker.github.io`, alle Dateien ins Root, Settings → Pages → main / root. Issues aktiviert lassen (Kontaktseite).
AdSense: Code an der Stelle `<!-- Google AdSense ... -->` in jedem `<head>` einfügen, danach `ads.txt` mit der eigenen Zeile anlegen.
